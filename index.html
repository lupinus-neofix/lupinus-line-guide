ルピナス訪問看護【公式】LINEの使い方

社内LINE（公式アカウント）・2026年9月8日版

シフト表の内容を、LINEで受け取ったり聞いたりできます。返事は自動で、通信料以外の費用はかかりません。

1. はじめに（最初の1回だけ）

  1. 配られたQRコードで 「ルピナス訪問看護【公式】」 を友だち追加する
  2. 案内が届いたら、自分の名前を送る。姓だけでもフルネームでも、スペースの有無も問いません
  3. 「〇〇さんとして登録しました」と返れば完了
青木
本店 青木（PT） さんとして登録しました。 「今日」「明日」「今週」で自分の訪問予定、「出勤」で今日の出勤者、「コメント」で自分宛てのコメント、「未完」で計画書・報告書の状況をお返しします。

同じ姓の人がいる場合は候補が返るので、そのどれかをそのまま送ってください。

4. キャンセルを報告する

ボタンだけで済む方法（おすすめ）

  1. 「キャンセル報告」を押す
  2. 今日 9/7(月) 明日 9/8(火) カレンダーで選ぶ 期間で報告 から選ぶ
  3. その日の自分の訪問がボタンで並ぶので、キャンセルになった訪問を押す
  4. 「【キャンセル登録】…」と返れば完了
  5. 続けて理由のボタンが出るので、分かれば選ぶ
  6. 最後に 完了 を押す。間違えていたら 取消（元に戻す）

理由を「入院」で登録しました。 完了 または、取り消しボタンを押してください。

理由は押さなくても構いません。その場合は「不明」で記録されます。自分で書く を押すと、文字で理由を送れます。

ボタンはその場限りです。別のメッセージを送ると消えます。あとから取り消したいときは、文字で 9/10 田中 キャンセル取消 と送ってください。理由を直したいときも、いったん取り消してから登録し直してください。

入院や外泊で何日も続けて休むとき

期間で報告 を押すと、開始日と終了日をカレンダーで選べます。最後に利用者名を送れば、その期間の訪問をまとめてキャンセルできます。文字でも送れます。

山田 9/7〜9/18 キャンセル 入院
9/7から18日まで山田さん入院でキャンセル
山田 9/7〜9/18 キャンセル 入院
【確認】9/7（月）〜9/18（金） 山田さん（本店） キャンセルする訪問 5件 　9/8（火） 10:00（青木） 　9/11（金） 10:00（青木） 　9/15（火） 10:00（青木） 理由：入院 この内容で登録しますか？
はい、登録するやめる

登録前に件数が出るので、確認してから押してください。訪問が無い日は飛ばします。期間は最大31日です。シフト表がまだ無い日は保留として記録し、できた朝に自動で色を付けます。取消 は期間ぶんをまとめて戻します。

文字で送る方法

9/3 山田 キャンセル
9/3 山田 キャンセル 発熱のため     ← 理由を付ける（任意）
山田 キャンセル                    ← 日付を省くと今日
9/3 山田 キャンセル 10:00          ← 同じ日に2回訪問があるとき
9/3 山田 キャンセル取消            ← 取り消す

取り消しは「キャンセル」と「取消」の両方の言葉が要ります。9/3 山田 取消 だけでは反応しません。

ふだんの言い方でも読み取ります。

明日の佐藤さん外泊のためキャンセル
【キャンセル登録】本店 9/7（月） 10:30 佐藤 の訪問（担当：井上） シフト表を変更しました。 理由：外泊のため 間違いなら「取消」を押してください。
取消（元に戻す）

登録すると、週間シフトのそのセルに色が付き、キャンセル集計に記録されます。その日のシフトに名前が見つからないときは「名前の表記を確かめてください」と返り、記録する やめる で選べます。打ち間違いなら「やめる」を押してください。

  2. 今日の自分の訪問先がボタンで出るので、利用者を選ぶ
  3. あとは内容だけ送る。「【連絡を付けました】…」と返れば完了。担当者には当日朝の訪問メモと「コメント確認」で届きます

田中さんへの連絡内容を送ってください。
本日下剤内服したため、次回訪問時に排便状況確認してください

取消 12:00 田中別の日にする

ボタンに無い利用者のとき

利用者名を入れて、普通に文章を送るだけです。名前は文のどこにあっても構いません。

田中さん本日下剤内服したため、次回訪問時に排便状況確認してください
本日下剤内服したため、次回訪問時に田中さんの排便状況確認してください

日付を省くと今日以降で最初の訪問に付きます。指定するなら 9/10 田中 …。文中に利用者が2人いるときは、どちらへの連絡かボタンで聞き返します。間違えたら 取消、日を変えるなら 別の日にする を押してください。

途中でやめたくなったら、やめる のボタンを押すか「やめる」と送ってください。聞き返しの状態が解除されます。

7. 朝のひとこと

その日はじめて「今日の出勤」か「今日の予定」を押すと、返事の先頭に天気とひとことが出ます。

☔ 30℃/24℃ 降水 午前80%・午後60% 🔮 段取りが冴える日。面倒な連絡を朝のうちに片づけると楽。 【9/9（水）の出勤】本店 5名 青木、井上、上田、江口、小川

1日1回だけです。2回目からは出ません。出勤と予定のどちらを先に押しても同じです。ひとことは人ごとに違います。

天気をもう一度見たいときは 天気 と送ってください。何度でも返ります。雨や猛暑、冷え込みの日は、朝に全員グループへ天気のお知らせが届きます。

8. 気をつけること

  • このLINEは社内専用です。利用者さんやご家族は入っていません
  • 届いた内容のスクリーンショットや転送はしないでください（利用者の情報が含まれます）
  • 返事は自動です。急ぎの連絡は電話で
  • 退職時は管理者が登録を解除します
困ったときは「使い方」と送ると案内が返ります。

スタッフ向けの内容に加えて、事務員には専用メニューが表示されます。ボタンを押すか、同じ言葉を文字で送ります。

2. キャンセルを代理で報告する

  1. 「キャンセル報告」→ 日付を選ぶ（今日 9/7(月) 明日 9/8(火) カレンダーで選ぶ 期間で報告）
  2. 「利用者名を入力してください」と返るので、利用者名を送る（例：山田、理由を付けるなら 山田 発熱のため）
  3. 「【キャンセル登録】本店 9/7（月）／10:00 山田 の訪問（担当：青木）」と返れば完了
  4. 続けて理由のボタンが出るので、分かれば選ぶ（押さなければ「不明」で記録）
  5. 理由を選ぶと 完了 取消（元に戻す） が出るので、確認して押す
9/7（月）のキャンセルですね。 利用者名を入力してください。

山田
【キャンセル登録】本店 9/7（月） 10:00 山田 の訪問（担当：青木） シフト表を変更しました。 理由を選んでください。 間違いなら「取消」を押してください。

  • 理由は「利用者都合／外泊・不在／不明／自分で書く／体調不良／入院／事業所都合」から選べます。文字で理由を付けて送った場合はボタンが出ません
  • 集計ファイルの「集計」シートに理由別の件数が出ます。あとから直すときは「一覧」シートのG列を編集してください
  • 入院・外泊などで続けて休むときは 期間で報告 を押すか、山田 9/7〜9/18 キャンセル 入院 のように送ります。登録前に件数の確認が出ます。訪問が無い日は飛ばし、期間は最大31日です。取消は期間ぶんまとめて戻せます
  • 拠点は3拠点を自動で探します。2拠点で同じ名前が見つかったときだけ拠点ボタンが出ます。河内 山田 のように拠点名を付けて送ることもできます
  • 同じ人の行に2回訪問があるときは 10:00 14:00 両方 のボタンで選びます
  • 当日のキャンセルは、その場で担当者のLINEにも「【本日キャンセル】…」と届きます。翌日以降はシートに色が付くだけです
  • 週間シフトがまだ無い先の日付は「記録する／やめる」の確認が出ます。記録しておくとシートができた朝に自動で色が付きます

文字で送るなら：9/7 山田 キャンセル 発熱のため、河内 9/7 山田 キャンセル（拠点指定）、9/7 山田 キャンセル取消。明日の佐藤さん外泊のためキャンセル のようなふだんの言い方でも読み取ります。

後から取り消すときは文字で送ってください。 ボタンはその場限りで、別のメッセージを送ると消えます。9/7 山田 キャンセル取消 のように、「キャンセル」と「取消」の両方の言葉を入れます。シフト表のセルの色は、塗る前の色に戻ります。

記録される利用者名は、打った文字ではなくシフト表の表記に合わせます（「小林②」→「小林」）。集計で同じ人がまとまるようにするためです。

3. 連絡を付ける（担当者へのメモ）

  1. 「連絡を付ける」を押す
  2. 利用者名を入れて、普通に文章を送る（例：田中さん保険証の写メお願いします）
  3. 「【連絡を付けました】…」と返れば完了
連絡したい内容を、利用者名を入れて送ってください。 (例)：9/10 田中さんの排便状況を確認してください 日付を省くと、今日以降で最初の訪問に付きます。
やめる
田中さん保険証の写メお願いします
【連絡を付けました】本店 9/10（木） 12:00 田中（担当：青木） 保険証の写メお願いします 当日朝の訪問メモと「コメント確認」で担当者に届きます。シートのセルにはメモとして付いています。
取消 12:00 田中別の日にする
  • 日付を省くと今日以降で最初の訪問に付きます（今日でも時刻が過ぎた枠は飛ばします）
  • 日付を指定するなら 9/10 田中 保険証の写メお願いします
  • 名前は文のどこにあっても構いません。保険証の写メを田中さんにお願いします でも付きます
  • 文中に利用者が2人いるときは、どちらへの連絡かボタンで聞き返します
  • 事務員はシフトの訪問枠に載っていないので、利用者を選ぶボタンは出ません。文章で送ってください
  • 取消 … 付けた連絡を消す。別の日にする … 付けた連絡を外して日付を選び直す

担当者には当日朝の訪問メモと「コメント確認」で届きます。週間シフトのセルにはメモ（黒い三角）として付きます。

4. 自分のコメント

自分が書いたコメント（シート上の吹き出し）と、LINEから付けた連絡のうち、まだ解決されていないものを一覧にします。

【加藤さんが書いたコメント・連絡】未解決 2件 ■9/10（木） 本店 上田　12:30 小林（連絡） 家族の意向確認 ■9/8（火） 本店 江口　12:00 中村 介護保険証の確認・写メお願いします。 ［削除］で連絡を消す、［済］でシートのコメントを解決済みにできます。
削除 9/10 12:30 小林済 9/8 12:00 中村

一覧は今日から3週間先まで。ボタンは13個まで（それ以上は先頭13件に付きます）。

シートのコメントは Google アカウントの名前で記録されます。名簿の設定は管理者が済ませています。一覧に自分のコメントが出ない場合は管理者に伝えてください。

5. 毎月の流れ

日何が起きるか事務の作業

27日 9:00翌日の文面の下書きが管理者・事務に届く土日や連休で日付を直したいときは LINE_文面 シートの本文を編集
28日 9:00全員グループに月末のレセプト案内なし
翌1日・3日 9:00未完のある本人へリマインドなし

「未完 全体」を送れば、いつでも同じ一覧が見られます。

6. キャンセル集計ファイル

Google ドライブの「キャンセル集計」に、LINEで報告されたキャンセルがすべて記録されます。

  • 月次確認シート：B列のプルダウンで年月・利用者・拠点を選ぶと該当行だけが並ぶ（月末の確認用）
  • 一覧シート：全件。理由の追記はここで
  • 集計シート：月別・拠点別・利用者別の件数

7. 気をつけること

  • 届いた内容のスクリーンショットや転送はしない
  • 返事は自動なので、急ぎは電話で
